# Rain Hou Portfolio

GitHub Pages-ready source for the portfolio website.

## Publish

1. Create a GitHub repository named exactly `<your-github-username>.github.io`.
2. Push all files in this folder to the repository's `main` branch.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment → Source**, select **GitHub Actions**.
5. Open **Actions** and wait for `Deploy portfolio to GitHub Pages` to complete.
6. Visit `https://<your-github-username>.github.io/`.

The workflow automatically rebuilds and republishes the site after future pushes to `main`.
